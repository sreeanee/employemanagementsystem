# EmployeManagementSystem

Full Stack Application using SpringBoot as Backend and React Front End using MySQL Database.

## Technical Overview
This project implements a comprehensive employee management solution leveraging a modern full-stack architecture:
- Backend: Java, Spring Boot
- Frontend: React.js
- Database: MySQL
- API: RESTful Services
